Safe to Omit, Worth Omitting?

Keeping the Answer and Cutting Latency When an LLM Agent Skips Another’s Message

Xinyang Li1, Chih-Hsuan Yang2*, Xiaolong Ma2, Anjir Ahmed Chowdhury1, Vikram Vasudevan3, Rajeev Thakur2, Feng Yan1

1 University of Houston2 Argonne National Laboratory3 Oregon State University* Corresponding author

Paper Code Dataset

When can an agent skip another agent’s message?

A receiver agent often waits for a helper agent’s message, sent as text or as the helper’s KV cache. We read the receiver’s confidence without the message and certify, with a finite-sample test, a threshold at which at most 5% of skipped answers change. Across five benchmarks and three model pairs, oracle headroom proves weak evidence that messages help: control inputs without answer-specific content reproduce a median 76% of the oracle’s gain. Whether a message can be skipped depends on how often and how predictably it changes the receiver’s answer. And safety does not determine efficiency: skipping text saves hundreds of milliseconds per query at batch size one, while skipping the KV cache saves far less.
